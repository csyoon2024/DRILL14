# 시간 기반 새 비행 애니메이션

## 실행

`LEC16_Time` 폴더에서 `python main.py`를 실행합니다. 게임 실행에는 프로젝트에서 사용 중인 `pico2d`와 `transitions`가 필요합니다.

## 새 편대 동작

- `bird_animation.png`의 5열 × 3행 시트에서 실제로 존재하는 14개 스프라이트만 사용하며, 마지막 빈 칸은 건너뜁니다.
- 새 객체를 정확히 10개 생성해 화면 상단에 5마리씩 두 줄로 배치합니다.
- 편대는 초당 180픽셀로 좌우 이동하고, 좌우 경계에서 남은 이동 거리까지 반사 계산에 반영합니다.
- 1초는 12 애니메이션 프레임으로 진행합니다. 이동과 날개 애니메이션은 프레임 횟수가 아닌 실제 프레임 시간(초)에 비례합니다.
- 기존 단위 기준인 10픽셀 = 0.3미터를 적용하면 비행 속도는 초당 5.4미터입니다.
